# 山野装备 · 已确认范围

用途：Java 后端求职。平台自营，实物装备销售；用户端、管理后台、独立微服务进程。

- 管理员维护单品、固定套装（组件及数量、套装价）、商品状态和库存。
- 单品与套装共享组件库存，套装可售数量取各组件可售数量的最小值。
- 服务端计算价格；订单保存名称、价格、组件与收货信息快照。
- 下单保留库存 15 分钟；取消和超时释放库存。
- 演示余额支付；支付幂等，通知失败可重试。
- 已支付且未发货的整单自动退款；退款退回演示余额并恢复库存。
- 管理员发货、用户确认收货；退款与发货竞争只能一方成功。
- 普通用户与管理员两种角色，服务端验证权限和订单归属。
- 名称“山野装备”，森林绿、米白、橙色；页面使用真实业务数据。
- 交付初始化数据、启动脚本、部署说明、关键流程验证结果。

公开仓库包含当前业务实现、前端、部署模板和验证文档。原始备份与旧环境配置仅保存在本机。
